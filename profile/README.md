# ModPorterMC

### Minecraft Mod Ports • Version Updates • Loader Conversions

ModPorterMC focuses on porting, updating, and modernizing Minecraft mods across versions, loaders, and platforms.

From straightforward version bumps to larger build, rendering, API, and compatibility migrations.

---

## Services

- Minecraft version upgrades
- Backports to older versions
- Fabric / Forge / NeoForge loader ports
- Build and Gradle modernization
- Deprecated API migrations
- Rendering and networking fixes
- Compatibility troubleshooting
- Paper/server-side rewrites where practical
